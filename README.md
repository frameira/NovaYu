# 中国公民防开户（开盒）指南

开盒，也叫开户，就是把躲在账号后面的真人挖出来，然后公开。

这本书讲两件事：怎么不让人把你的信息拼成一份完整档案，以及已经被拼出来之后怎么办。

写给普通人看。只讲怎么防、怎么维权，不讲怎么查别人。

**在线看**：<https://frameira.github.io/NovaYu/> ，手机直接打开。

**下载**：[PDF 版](防开盒指南.pdf) ，离线看、打印出来给家里人看都方便。

**没时间看**：先看[十分钟版](docs/00-10分钟版.md)。**已经出事了**：直接看[应急卡](应急卡.md)，一页纸，可以直接转发。

正文里带方括号的标注是来源类型：`[官方]` `[法律]` `[标准]` `[平台]` `[案例]` `[经验]`。说明见 [6.8 来源与延伸阅读](docs/06-附录.md#68-来源与延伸阅读)。

## 序言

在中国互联网的历史长河里，往往伴随着黑客攻击、数据泄露、开盒。它有很多名字：开户、人肉搜索。

当一个陌生人拿着你的身份信息恶意散布，用电话和短信骚扰你，我相信任何一个正常人都会感到害怕与无助。互联网上确实有一部分心理变态，拿随意开盒开户取乐，把自己的恶趣味建立在别人的担惊受怕之上。

电视剧里有句台词："10 分钟内，我要这个人的全部信息。"所谓背调、尽调，有些也是建立在开户开盒之上。但现实里极少有一次查全的——多数是几条线索慢慢拼，耗时几小时到几周，中间还经常拼错。

本仓库由网络安全专家余鑫隆创建，旨在减少中国互联网的开盒、开户乱象，让大家可以尽可能的保护自己的隐私。

这份指南只能帮你挡掉大概八成的开盒手法。到目前为止，没有任何手段可以让人完全不被开盒。

好消息是局面在收紧：国家在收紧公安的查询权限，平台也在收紧查询权限，大部分数据已经做了脱敏。

作者：余鑫隆，英文名 NovaYu，05 后，16 岁起担任某单位网络安全顾问，中国最年轻的网络安全专家之一，曾获《北京日报》报道，专注 Web 与区块链网络安全，孙宇晨门徒。

联系邮箱：iamnovayu@gmail.com

这份指南只针对中国大陆居民。香港特别行政区、澳门特别行政区、台湾省不在本书范围内。
