# 第七部分 未成年人和家长

未成年人被开盒的比例不低，而且有两个特点：**信息本来就少，一旦被开，伤害特别大**；**遇到事通常不敢跟家里说**。

这一部分写给两拨人：孩子自己，和替孩子操心的家长。

## 7.1 孩子的信息从哪里漏出去

- 学校、班级的公示名单：全名、班级、学号，有的还有身份证号
- 家长自己发在朋友圈和群里的照片：校服、校徽、校门、奖状上的全名
- 家长群备注："某某妈妈"，把家长和孩子的名字绑在一起
- 学校和培训机构的报名表，会被转手
- 孩子自己用的 App：游戏、社交、短视频，注册时填的资料
- 学校发的在线表格，链接可能被转发到外面

## 7.2 给孩子配手机之前，先做这几件事

- 账号用家长的手机号注册，别用孩子自己的号
- 关掉：通过手机号找到我、通讯录推荐、附近的人、同城展示、位置共享
- 只装必要的 App，每个 App 都关掉通讯录和相册权限
- 相机的定位关掉
- 头像不用真人照，昵称不带真名和生日
- 学校、班级、校服、校门，一律不发

## 7.3 孩子自己要记住的四句话

1. 网上不要写真名、学校、班级、住址
2. 有人问这些，不要答，回来告诉家长
3. 跟人吵架了就停，不要互相骂
4. 出了事第一时间告诉家长

最后一条要反复说。

孩子最常做的事，是害怕被骂，于是自己删掉聊天记录、自己处理。结果是证据没了，对方更嚣张。

## 7.4 孩子被同学开盒了怎么办

**先判断到了哪一步。**

- 只是同学翻到了 QQ 空间的老内容：先找班主任，同时联系对方家长
- 已经发到群里、发到网上：平台举报、学校、报警，三条线一起走
- 伴随辱骂、威胁、造黄谣：直接报警，不要在学校内部消化

**三件事同时做。**

**一、找学校。**

班主任、德育处、校长。要求学校出面制止，并且留下书面记录。学校对校园欺凌有处理责任。

**二、找平台。**

举报理由选"泄露隐私""涉及未成年人"。平台对涉及未成年人的信息处理更快。

**三、报警。**

带证据去派出所。涉及未成年人的案件，处理力度更大。

**注意：**

- 不要让孩子自己去跟对方理论
- 不要在班级群里公开对骂，那只会扩大传播
- 保留所有证据，包括孩子被骂的聊天记录
- 如果孩子出现厌学、失眠、自伤，立刻看心理医生，或者打 12356

## 7.5 家长最容易犯的三个错

**一、自己先把孩子的信息发出去了。**

生日、学校、班级、奖状、准考证、录取通知书，这些都是敏感信息。

发之前问自己一句：这条信息，陌生人看了能做什么？

**二、出事后第一反应是骂孩子。**

孩子被开盒，多半不是因为做错了什么。第一句话如果是指责，第二句话你就听不到了。

**三、删证据。**

看到孩子手机里的骚扰信息，很多家长第一反应是删掉、拉黑。

**先截图，再拉黑。**

## 7.6 给家长的检查清单

- [ ] 朋友圈里孩子的照片，有没有带学校、校服、校门、奖状全名
- [ ] 家长群、班级群的备注，是不是"某某妈妈 + 真名"
- [ ] 孩子的设备有没有关掉位置和通讯录权限
- [ ] 孩子的账号绑的是谁的手机号
- [ ] 学校发的在线表格，链接有没有被转发到外面
- [ ] 跟孩子说过"出事了先告诉家里"吗

## 7.7 法律上，未成年人有特别保护

- 《未成年人保护法》对未成年人的个人信息有专门规定
- 《个人信息保护法》把不满十四周岁未成年人的个人信息列为**敏感个人信息**，处理要取得监护人同意
- 涉及未成年人的网络欺凌、隐私泄露，平台和学校都有处理义务

报案和举报的时候，明确说一句"涉及未成年人"，处理层级会不一样。
