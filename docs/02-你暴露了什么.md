# 第二部分 你暴露了什么

想防住，先得知道自己漏在哪。

这一部分不讲怎么防，只讲你身上有哪些口子。

## 2.1 先列一张自己的单子

拿张纸，或者开个本地文件，把这些写下来：

- 你有几个手机号，哪个是主号，分别绑了哪些平台
- 姓名、身份证号、户籍地
- 常用邮箱，还有几个备用邮箱
- 微信、QQ、微博、抖音、小红书、贴吧、知乎、B 站的账号
- 收件地址、常用的外卖地址、打车常用地址
- 银行卡预留的手机号
- 常联系的家人、同事
- 你在网上发过的照片、视频、截图

写在纸上，或者存在自己电脑里。

别放网盘，别发到微信收藏，别存进邮箱草稿箱。

这份单子本身就是一份档案，只不过写的人是你自己。

## 2.2 手机号是钥匙

手机号是使用率最高的身份标识。注册要它，找回密码要它，收验证码要它。

拿到你的手机号，等于拿到一把能试遍你所有账号的钥匙。[经验]

**号码本身就是信息。**

- 前几位是号段。看号段能知道你用的是哪家运营商，也能看出是不是虚拟运营商（170、171 这类）
- 号段还登记了放号地。网上查"手机号归属地"，查的就是运营商公布的号段表，只能查到号段登记在哪儿，而且携号转网之后，连运营商都可能变
- 后面几位是分给你的用户号码，里面不写城市

这里要纠正一个很常见的说法：**手机号的中间几位不是城市编码，读不出你在哪。**

座机才有区号，010、021 那种，那个才是直接写在号码里的城市编码。

所以光看一个手机号，对方能知道的是：大致哪家运营商、哪个号段、号段登记的归属地。[官方]

**归属地不等于你人在哪。**

**名下有几个号，你可能自己都不知道。**

以前办过的卡、给家人办的副卡、公司发的卡，可能都还挂在你名下。

"一证通查"能查出来（怎么查看 3.2）。

只要有一个号不是你在用，当天就去注销。

实名制下，这个号登记在你名下。出了事，第一个被找上的是你，你得先花力气去证明那不是你干的。

不是"责任一定是你的"，是"**麻烦一定先是你的**"。

**二次放号。**

你注销的号，运营商会放出来重新卖。

下一个买到它的人，能用短信验证码进你那些没解绑的老账号。

反过来，你现在用的号，也可能是别人用过的。[官方] 运营商号码回收再放号机制

去运营商 App 里搜"二次号码焕新"，能把前任机主绑过的互联网账号批量解绑。各家叫法不同，以你当地运营商为准。[官方] 运营商提供的号码焕新服务

**换号要做的解绑清单。**

换号不是去营业厅办一下就完事。下面这些都要改：

- 钱：所有银行卡的预留手机号、支付宝、微信支付、证券
- 社交：微信、QQ、微博、抖音、小红书
- 政务：社保、公积金、医保、交管 12123
- 出行：12306、航旅纵横、打车、共享单车
- 生活：外卖、电商、快递、物业、各种会员卡
- 工作：企业微信、钉钉、公司邮箱

旧号别急着注销。留一两个月专门收验证码，确认没有遗漏了再销。

**手机号还留在这些地方。**

快递面单、外卖单、门店会员登记、招聘简历、学校公示、业主群、二手交易、停车扫码。

这些地方的信息都是纸面的、公开的、没人管的。

## 2.3 身份证别乱给

身份证号 18 位。前 6 位是户籍地的行政区划代码，中间 8 位是你的生日，最后 1 位是按前面 17 位算出来的校验位（为什么这三样别同时公开，看 3.8）。

这两段本身就是信息：暴露你哪年出生、户籍在哪个区县。

**这些场合必须给：**

办银行卡、办手机卡、住酒店、买火车票机票、寄快递、医院挂号、办护照通行证、入职。

**这些场合不需要给：**

办理发店会员卡、健身房、试听课程、超市积分、停车登记、抽奖活动、网上下个资料、进小区访客登记。

遇到后面这些，你有权利不给。要么说没带，要么说只留名字和电话。

**手持身份证照，尽量别拍。**

这类照片是身份冒用的第一手材料。网贷、注册空壳公司、批量注册账号，用的就是这么一张图。

非要拍，拿张纸写清楚"仅供某某平台实名认证使用，他用无效"，跟身份证一起拍进去。

**复印件也要处理。**

用蓝笔在空白处写"仅供办理某某业务使用，他用无效"。字要压住一部分身份证的影像，但别遮住姓名和号码。最后写上日期。

这一行字，是防别人拿你的复印件去别处用的。

## 2.4 社交账号的开关

平台默认帮你开着的功能，比你想象的多。

**微信**

- 添加我的方式：微信号、手机号、QQ 号、群聊、二维码、名片
- 允许陌生人查看十条朋友圈
- 朋友圈可见范围：改成三天或者半年
- 附近的人：不用就关，用过之后清除位置
- 向我推荐通讯录朋友

**QQ**

- 允许通过手机号、QQ 号搜索到我
- 空间的访问权限、动态的可见范围
- 登录设备管理，不认识的设备踢掉

**微博**

- 手机号搜索、真实姓名展示
- 发博默认带定位
- 关注列表、粉丝列表是否公开
- 资料里的生日、学校、公司

**抖音**

- 向我推荐通讯录好友
- 同城展示、作品带位置
- 谁可以评论、谁可以 @ 我
- 抖音号别做成跟微信号、手机号一样

**小红书**

- 手机号搜索、通讯录推荐
- 笔记带位置
- 绑定信息的对外展示

**贴吧、知乎、B 站**

- 历史发言是公开的，很多年前说的话也能被翻出来
- 关注列表、收藏夹有时也是公开的
- 这些平台的老号，往往绑的是你已经不用的旧手机号

有三件事每个平台都有，挨着关一遍就行：手机号能不能被搜到、要不要匹配通讯录、位置展不展示。

具体每一项在哪个菜单下，各平台版本不同，以你手机上的实际界面为准。[平台]

## 2.5 快递和地址最实在

快递面单上有你的名字、电话、地址，有的还有你买了什么。

现在很多平台默认用隐私面单：电话打码、名字只留姓。但不是所有快递、所有驿站都这样。[平台] 各平台规则不同，以下做法不依赖平台

驿站签收的那张单子，往往什么都没处理。

今天就能做的几件事：

- 地址写到小区或者驿站，不写门牌号，不写楼层
- 收件名字用化名
- 拆完的快递单，把名字、电话、地址那几行涂掉或者撕碎
- 退货地址填驿站，别填家里
- 外卖备注别写"放门口鞋柜""门没锁"这类话——那等于告诉别人你家的结构和你在不在家

## 2.6 出行、住宿、消费

- 火车票、机票都是实名，行程单上有全名和证件号
- 酒店入住要登记身份证，很多还要留手机号
- 打车、共享单车的行程记录里，有你家和公司的位置
- 外卖、电商的地址簿里，存着你所有用过的地址

登机牌、车票、房卡别拍照发出来。

上面的二维码扫一下，能扫出姓名、证件号后几位、行程。

行程也别实时发。今天发"在三亚"，等于告诉所有人你家现在没人。

## 2.7 公开数据里的你

这一节最容易被忽略，也最容易查到。下面这些不用查库、不用花钱，搜就能搜到。

**企业信息**

开过公司、做过个体户、当过股东或法人，你的名字、公司注册地址、注册电话，在公开的企业信息平台上都能查到。

企业年报里留的联系电话，很多就是老板本人的手机号。

**裁判文书和执行信息**

打过官司、被强制执行过，文书是公开的，里面有姓名、出生年月，有的还带住址。

**招投标和中标公示**

投标要留联系人、电话。中标结果会公示，附件里经常带着项目成员的姓名和手机号。

**招聘网站的简历**

很多平台的简历默认对企业、猎头可见，手机号能直接下载。

**学校和单位的公示名单**

奖学金、录取名单、评优名单、值班表，经常是 Excel 直接传到官网，里面全名、学号，有的连身份证号都有。

**单位通讯录**

有些单位的内部通讯录 PDF 会流到网上，或者被传到文库类网站。

**GitHub 和代码仓库**

提交记录里的邮箱是公开的。很多人用的就是私人邮箱，甚至是真名邮箱。

**域名 WHOIS**

注册域名时填的姓名、邮箱、电话。现在多数有隐私保护，但历史记录会被第三方存档，一样查得到。

**学术论文、专利、软著**

作者信息里有单位和邮箱。

**商家平台**

大众点评、美团上的商家电话，很多就是老板本人的号。

做法很简单：**拿你自己的名字去搜一遍。**

加上城市、加上公司、加上学校，一条一条点开看。

你会知道别人能搜到什么。

## 2.8 照片会说话，先认识 EXIF

照片的原始文件里带着一段隐藏信息，叫 EXIF。[标准] Exif 标准，JEITA CP-3451

EXIF 里可能有这些字段：

- 拍摄时间，精确到秒
- 设备型号，甚至镜头型号
- **GPS 坐标**，也就是拍摄地的经纬度
- 图像方向、处理软件

**先纠正一个误解：不是每张照片都能查到 GPS。**

有没有、还剩下多少，取决于四件事：

**拍摄设备、系统设置、文件怎么处理、发到哪个平台。**

- 相机 App 没拿到定位权限，压根就没有 GPS 这一条
- 有些 App 拍完直接上传，原始文件根本没落到你手里
- 平台转码、压缩、加滤镜，大部分字段会被丢掉
- 截图、二次编辑、重新导出，一般只剩很少甚至没有

**同一张照片，走不同的路，结果完全不同。**

一部开着定位的手机拍的照片，往下走：

| 走的路径 | EXIF 还剩什么 |
|---|---|
| 相机里的原始文件 | 全套：时间、机型、GPS、拍摄参数 |
| 发微信，勾了"原图" | 基本保留，GPS 常常还在 |
| 发微信，不勾原图 | 被压缩，GPS 一般会被去掉 |
| 发微博、抖音、小红书 | 平台会重新压缩转码，多数字段会丢，但**不保证**，别当保险 |
| 截图 | 基本没有。截图有自己的信息，但不含拍摄地点 |
| 二次编辑：裁切、加滤镜、重新导出 | 看用什么工具。有的清干净，有的把原始信息一起写回去 |
| 邮件附件、网盘、论坛传原文件 | 全套保留，一点不少 |

**所以真正危险的是两种东西：原图、原文件。**

压缩过的、截图出来的、转过几手的，风险明显低——但"低"不等于"没有"，自己验一遍最稳。

**EXIF 之外，照片本身也在说话。**

- 窗外的楼、地标、山形，能定位到城市甚至小区
- 门牌号、单元号、电梯里的楼层显示
- 工牌、门禁卡、快递单、外卖单
- 车牌、车型
- 孩子的校服、书包上的姓名牌
- 固定的机位和视角，几张照片一比，能看出你家在几层、朝哪边
- 瞳孔、眼镜、手机屏幕的反光，能把拍照的人或者屏幕内容还原出来

视频也一样。背景音里的方言、门铃声、地铁报站、邻居说话，都能用来定位。

## 2.9 截图也会说话

这是最容易被忽略的一类。

一张随手发的截图，可能带着：

- 手机状态栏：运营商、信号、电量、时间、定位图标
- 聊天列表、群名称、联系人的备注
- 输入法联想出来的词
- 平台自带的水印，上面有你的账号 ID
- 截图里别人发的信息——你替他泄露了

发截图之前，把状态栏裁掉，把聊天列表挡住，把水印裁掉。

## 2.10 家人是最软的一环

你的信息泄露，被骗的往往是他们。

- 你的紧急联系人、通讯录同步，暴露了你和谁有关系
- 家长群里的备注"某某妈妈"，等于把你的真名和孩子绑在了一起
- 亲友的社交账号、关注列表、合照，能反推出你们的关系
- 婚礼、家庭聚会的照片里，全是关联线索

有人冒充你给家里人打电话，说"我出事了，快打钱"。

现在还有用 AI 模仿声音、模仿脸打视频的。

这一招到现在还有人上当。

## 小结

这一部分不是让你把信息全删掉，是让你知道自己漏在哪。

下一部分教你怎么自己查一遍。

## 2.11 有人直接来问你

前面讲的都是信息"被动"流出去。这一节讲"主动"被套走。

**先记住一条总原则：**

没有任何正规机构，会在电话、短信、私聊里向你索要完整的身份证号、银行卡号、验证码，或者手持身份证照。

- 银行不会问你的密码和验证码
- 公安不会打电话让你转账，也不会让你下载 App"配合调查"
- 平台客服不会要你的登录密码
- 快递公司不会用私人号加你微信，要你的身份证照片

**七套常见话术。**

**一、"核对信息"。**

"我这边核对一下您的收货地址，请问是 XX 路 XX 号吗？"

前半句他是故意说错的，等你纠正。你一纠正，地址就到手了。

应对：不纠正，不补充。问他是哪个平台、工单号多少，然后自己去官方 App 看。

**二、"理赔、退款"。**

"您的快递丢了，我们给您理赔，需要您提供身份证号和银行卡号。"

应对：挂掉，自己去购物平台看物流。平台不会让快递员私下找你理赔。

**三、"入职背调"。**

"入职前需要您提供身份证正反面，还有手持身份证照。"

应对：正规背调不需要手持照。先确认对方公司是不是真的，非拍不可就加水印纸（见 2.3）。

**四、"老同学、老朋友"。**

"你还记得我吗？我们以前……你现在在哪上班？"

应对：别报单位，别报城市。让他先说自己是谁。

**五、"改价、验货"。**

二手交易里的："你发个订单截图给我""你把商品信息发我，我改价"。

截图里有你的订单号、姓名、电话、地址。

应对：只走平台站内消息，不发任何截图。

**六、"我帮你查查是谁"。**

"网上有人开你盒，我帮你查。"

这是专门骗正在恐慌的人的。你一配合，就轮到你被套了。

应对：不理会，直接走 5.4 和 5.5。

**七、"免费测一测"。**

帮你看"你的信息泄露了多少""输入手机号查一下"。

这是来收料的。见 3.4。

**怎么判断对方是不是真的。**

- 挂掉，用官方渠道打回去。号码在卡背面，客服在 App 里
- 不听他念的信息，只看你自己查到的信息
- 任何"不要挂电话""不要告诉家里人""抓紧时间"的要求，本身就是诈骗标志
- 96110 打来的电话要接，但别人自称是 96110 不算

**如果已经被套了。**

别慌，也别觉得丢人。这是专业话术，很多人中过。

1. 记下时间、对方号码、说了什么
2. 改掉相关账号的密码
3. 拉黑，别再联系
4. 如果给了身份证号或者银行卡号，按 5.1 走一遍
5. 保留记录，有必要就报警

**一句话：**

你在电话里说的每一句话，都可能被记下来当线索。

**少说，比什么都管用。**
