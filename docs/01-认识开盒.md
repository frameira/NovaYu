# 第一部分 认识开盒

## 1.1 什么是开盒（开户）

有人拿着你的手机号，去社交软件上翻你在平台留的信息，翻出你的实名、地址、家人。

这就叫开盒。

它还有两个名字：开户、人肉。开户是躲关键词审核的谐音写法，跟银行开户没关系。

开盒分三步：先拿到信息，再把这些信息对上号，最后发到网上或者打电话骚扰你。

第一步你防不住。信息在平台、在运营商、在快递公司手里，你管不了。

你能防的是第二步：别让这些线索对上号。

被翻出来的东西，无非这几类：

- 姓名和身份证号
- 手机号、邮箱、微信号
- 户籍地址、住址、收件地址
- 配偶、父母、子女、同事
- 开房、出行、快递、消费、就医记录
- 各个平台的账号，和你在上面说过的话
- 人脸、手持身份证照、密码和验证码

最后这条要说一句：手机号能换，密码能改，人脸换不回来。

以后谁让你手持身份证拍照，先想三秒。

这些信息不是一次泄露凑齐的。是你自己发一点，平台存一点，运营商登记一点，线下办业务再留一点。

单看每一处都不多。对上号，就是一份完整档案。

所以防的重点就一句话：别让几条线索能对上。别指望哪个网站永远不出事。

动手的成本很低，几百块、几分钟。你的代价是换号、搬家、被骚扰几个月，家里人还可能被骗钱。

这就是为什么值得花两个小时，提前把口子收一收。

这里要分清两种数据，来路不同，危险程度也不同。

一种是社工库里的老库。公开流传的，多是好几年前拖走的，集中在 2016 年前后。

另一种是行业里正在流动的新料。你现在用的电话、住址、订单，多半来自学校、航司、快递这些环节的内部泄露，是新的。

老库的问题是过时：旧号你早不用了，它基本就对不上你了。

但旧号还在你名下，或者还绑着你的老账号，它就还是一把钥匙。

**别因为"流传的都是老库"就放松。**

你现在正在用的电话、住址、订单，属于新料，它不过时。新料是现在进行时，只能靠少给、分开放来防（看第四部分）。

先去查一遍：哪些老账号，绑的是你早就不用的号。

## 1.2 开盒的组成方式

一共三种。

### 一、社工库

就是超级 App 的数据库被黑客拖走（业内叫脱库），集中放到一起，加个索引用来查。

社工库里公开流传的，基本都是老库，好几年前拖走的。[经验]

网上常说 QQ 8 亿、微信 10 亿、微博 5 亿、支付宝 10 亿，加起来上百亿条。这些数字是黑产自己说的，重复、注水，信不过，你听个量级就行。

能确定的只有一件事：QQ 的数据很老。查一下你的老 QQ，绑的是不是早就没用的号。

微信这边以前有过通过流量分析关联手机号的漏洞，腾讯已经补了。我只说结论，不说怎么做。

记住一句：补了不等于永远安全。

### 二、信息贩卖

主要是学校、航司、快递行业的人往外卖。

这一类已经有不少判例，快递行业尤其多。案例和判决结果列在 6.8。[案例]

这些是新数据，你正在用的姓名、电话、地址、订单，还能成套对上。比社工库危险。

### 三、内鬼查询

有查询权限的人违规查你。公安、社保、银行都出过事。

这块我不讲怎么做，只说结果：这是刑事犯罪，《刑法》第二百五十三条之一，侵犯公民个人信息罪。

还有一种更麻烦的：有些单位的对外查询接口本身有漏洞，能被成批调用。

这不是某个人偷看，是一个口子被人打开了。

这种你个人防不住，只能靠上面去修。但如果你发现自己的信息是从这类地方流出来的，报案时一定要说。

如果对方报出的信息只有某个系统里才有，报案时一定写进去，这类案子查法不一样。

三种来源，一个解法：别让单独一条信息就能指到你。

## 1.3 一条信息怎么拼成一份完整档案

很多人问，我什么都没做，怎么就被查到了？

因为信息是散的，总有些东西能把这些散的信息串起来：

- 手机号，几乎所有平台都要，最危险
- 邮箱，注册和找回密码都用它
- 同一个昵称、同一个头像，很多人全网都用一套
- 同一个密码，一个站泄露，别的站就跟着被撞
- 同一台手机登录过的账号，也会被关联

串起来靠的是对得上。一条只是猜，两条能印证，三条基本就确认了。确认了，才开始挂人、打你电话。

举个例子。对方手里只有一个手机号。

他搜到一个二手帖子，帖子里留了微信。

微信昵称跟另一个平台一样。

那个平台上发过录取通知书。

通知书上有学校和姓名。

四步，全是公开信息，没动任何库。

所以防的重点不是删哪一条，是别让它们能串起来。

## 1.4 这些数据最后流到谁手里

搞清流向，你才明白为什么有些电话能精准到你自己都吓一跳。

**第一手，是拿到数据的人。**

有查询权限的岗位人员、脱库的人、批量采集面单的人。他们一般不直接骗你，他们卖数据。

**第二手，是料商和中介。**

把数据归类、清洗、打包，按类目卖：机票数据、快递数据、车主数据、股民数据、宝妈数据。

类目越细，价格越高。因为越细的数据，越好骗。

**第三手，是买家。**

- 电诈团伙，最常见
- 营销公司，打推销电话
- 催收和私人调查，拿来找人
- 还有一小部分，就是开盒骚扰你的人

**为什么会流到境外。**

这些数据会被打包卖到境外，在境外的通讯软件群组里分销。

境外园区里有专门的"数据组"，把数据分给话务组，话务组照着剧本打电话。

难追，是因为服务器在外面、人在外面、钱也在外面。

**为什么他们知道你的航班。**

机票退改签诈骗就是这么来的。姓名、证件号、航班号、起飞时间，都在那份数据里。[经验]

接到"航班取消，给你退改签"的电话，直接挂掉，自己去航司官方 App 或者打官方客服核实。

**为什么他们知道你的快递。**

快递面单被批量采集，或者电商订单数据被卖出去。常见剧本是"你的快递丢了，给你理赔"。[经验]

接到这种电话，挂掉，去购物平台里自己看物流。

**记住一个判断标准。**

能一口报出你姓名、航班、订单、住址的电话，不是熟人，是拿着你数据的人。

**你能做的：**

- 96110 打来的电话要接，装国家反诈中心 App
- 手机里把陌生号码静音
- 快递地址用驿站——少一张面单，就少一条数据
- 出境的数据你拦不住，但你能让自己那条又旧又不全

## 1.5 谁在开盒

按动机分，大概这么几类。

**为了取乐的人。**

闲着没事，拿别人的信息当玩具。多半混在特定的群里，互相"交作业"。

这类人没有明确目标。你被选中，可能只是因为你的 ID 好记、头像好看，或者你回了他一句。

**为了报复的人。**

你在网上跟他吵过、给过他差评、退过他的货、游戏里赢过他，或者你跟他分手了。

这类人只盯着你。他可能已经知道你是谁，也可能正在拼。后果通常是电话、短信、寄东西。

**为了钱的人。**

- 卖数据的：不针对个人，按类目批量卖
- 敲诈的：先查你，再拿你的信息找你要钱
- 诈骗的：手里有你的数据，打电话演戏

**饭圈和网络暴力。**

粉丝群体互撕，"人肉对家"是被默许甚至被鼓励的。

这类人最多、动作最快，而且会去骚扰你的单位、学校和家人。

**熟人。**

这是最容易被忽略的一类：同事、前同事、前任、同学、邻居、亲戚。

他们本来就知道你很多事，开盒对他们来说只是把你的信息发出去。

**很多开盒案的起点，是熟人。**

**最后一种：不该查却查了的人。**

有查询权限的岗位人员。见 1.2 第三条。

一句话总结：**你不需要做错什么，只要被人注意到。**

## 1.6 什么行为会招来开盒

下面列的是触发点。不是说做了就一定被开盒，是说这些场景下风险明显升高。

**一、网上对骂。**

任何平台的对骂都可能升级。对方吵不过你，就会去查你。

最危险的一句话是"你有本事来找我"。

骂完就拉黑。别给对方情绪，也别给对方线索。

**二、差评、退款、投诉。**

给商家差评、要求退款、投诉骑手、举报卖家。

你有理，但对方手里有你的姓名、电话、地址。

有话走平台流程。别加微信私聊，别接受"给你钱，你撤诉"。

**三、二手交易。**

买家和卖家都能看到对方的一部分信息。纠纷一起，地址就成了武器。

用驿站地址，不发快递单截图，不加微信。

**四、游戏和社交平台。**

游戏里被骂、被举报、抢装备、开挂冲突。

游戏 ID 常常跟其他平台重名，这是最短的一条线。

游戏号用单独的昵称和头像。

**五、饭圈、超话、小组。**

粉丝互撕是人肉的重灾区。你的关注列表、超话等级、发过的照片，都是线索。

追星的号跟生活号分开，别放自拍和定位。

**六、直播和内容创作。**

打赏纠纷、粉丝脱粉回踩、同行竞争。具体怎么防，看 4.10。

**七、情感纠纷。**

分手、离婚、追求被拒。对方手里可能有你的照片、聊天记录、家庭情况。

这类最难防，也最该提前处理：**分手的时候，把账号密码、共享位置、家人联系方式，全部切断。**

**八、求职和招聘。**

简历上有你的全名、电话、学校、经历。有人专门收集简历卖钱。

简历用专门的号，别写家庭住址，别上传手持身份证照。

**九、在群里跟人吵架。**

群里的备注、群名片、历史发言，都能被截图。

最典型的一句：**群昵称写成"真名 + 公司"，等于自己签名。**

**总结一句：**

开盒的起点往往不是你的信息泄露了，而是有人**盯上你了**。

信息可以提前收，情绪当场收不住。
