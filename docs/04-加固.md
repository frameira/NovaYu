# 第四部分 加固：把口子一个个堵上

前两部分说的是你的信息漏在哪。这一部分说怎么堵。

## 4.1 手机号分层

按用途分成三层：

**主号**：只给银行、政务、公司、家人。永远不发到网上，不注册任何论坛、游戏、二手交易。

**生活号**：外卖、快递、电商、门店会员。可以给商家，但不给陌生人。

**网络号**：论坛、贴吧、乱七八糟的注册。泄露了直接扔。

实际怎么弄：办一张副卡，或者单开一张便宜的低价卡当网络号。

一个号只干一件事。这样就算泄露，损失也是可控的。

旧号的处理顺序是：先挨着解绑，再留一两个月收验证码，最后才去注销。

## 4.2 关掉两个开关

这一条是全书最要紧的操作。

针对 3.3 说的那个问题，两个开关必须关：

1. **允许通过手机号找到我 / 搜索到我**
2. **向我推荐通讯录好友 / 允许通讯录匹配**

关完之后，别人就算拿到了你号码的一头一尾，也没法在平台上把中间几位确认出来。

挨个平台关一遍：

- **微信**：设置 → 朋友权限 → 添加我的方式（微信号、手机号、QQ 号、群聊、二维码、名片）；再把"允许陌生人查看十条朋友圈"关掉
- **QQ**：设置 → 隐私 → 加我为好友的方式；再接动态权限、登录设备管理
- **支付宝**：设置 → 隐私 → 常用隐私设置 → 关闭"可通过手机号搜索到我"，关闭"向好友公开我的真实姓名"
- **淘宝、闲鱼、拼多多**：隐私设置里的手机号搜索、通讯录推荐、真实姓名展示
- **微博**：隐私设置 → 手机号可搜索、关注列表可见
- **抖音**：设置 → 隐私设置 → 通讯录推荐、同城展示、作品可见范围
- **小红书**：设置 → 隐私 → 不把我推荐给通讯录好友、手机号搜索

**关完要自测。**

找个朋友，拿你的手机号去搜你。搜不到，才算关好了。

有些平台的"手机号搜索"关不掉。那就把资料和动态对外收起来，让别人搜到也没东西看。

关一个平台不算完。花一个下午，一次关干净。

## 4.3 昵称和头像别全网一样

同一个昵称、同一个头像，就是把几个账号串起来的那根绳子。

**昵称怎么起：**

- 主号可以用真名，这是给熟人看的
- 网络号用随机字母数字组合，别用姓名拼音
- 别用生日、手机号尾号、QQ 号、学号
- 别在所有平台都写同样的简介，比如都写"某某大学 程序员"

**头像要注意：**

头像能被以图搜图反查。拿同一张头像在全网用，等于自己把账号串起来了。

私人号和网络号用不同的头像。网络号用不相关的图，或者生成的图。

## 4.4 密码和找回方式

一个账号一个密码。记不住就用密码管理器。

密码长度比复杂度重要，12 位以上的随机串。

**二次验证的优先级，从强到弱：**

1. App 生成的动态码（TOTP 这类）
2. 硬件密钥
3. 短信验证码

短信验证码最弱，因为它能被冒名补卡截走。

所以去运营商设置一下：补卡需要服务密码。服务密码别告诉任何人。

**找回方式是最容易被忽略的一环。**

- 恢复邮箱的安全级别，要和主账号一样高
- 密码找回的安全问题（母亲姓名、出生地、第一所学校）别填真的，这些都能被查到
- 定期清理登录设备列表，不认识的踢掉

**验证码谁也不给。** 自称客服、公安、银行、快递的，要验证码的都是骗子。

邮箱单独说一句：开登录二次验证，并且定期检查有没有被设置自动转发规则。

## 4.5 别把身份证信息凑齐

回头看你 3.8 的结果。

**户籍地、出生年月日、性别，这三样别让人同时拿到。**

具体怎么做：

- 社交账号的生日填假的，或者不填
- 资料页的性别，能不填就不填
- 简历、群备注、老乡群、家长群里，别说自己是哪里人
- 手持身份证照，能不拍就不拍
- 非拍不可，拿张纸写"仅供某某用途使用"，跟证件一起拍进去
- 复印件用蓝笔写用途、压边、写日期（见 2.3）

如果发现被冒名注册了公司、网贷、账号：

- 去市场监管部门申请撤销登记
- 去平台申诉，要求注销
- 全程保留记录，这些是你后面报案和维权的材料

## 4.6 地址

- 写到小区或者驿站，不写门牌号，不写楼层
- 收件名字用化名
- 快递单撕碎再扔，或者把名字、电话、地址那几行涂掉
- 退货地址填驿站
- 外卖备注别写"放门口鞋柜""门没锁"
- 定期清理外卖、打车、电商里的常用地址，尤其是搬家以后
- 别晒新家的装修、门牌、小区大门、门锁

## 4.7 照片

- 关掉相机的定位功能
- 发之前去掉 EXIF（方法见 3.6）
- 别发原图
- 记住哪条路最危险：**原图 > 压缩过的图 > 截图**。发之前先想一下自己发的是哪一种
- 裁一下背景
- **打码用实心色块**：马赛克和模糊不是绝对安全。小面积、小字的模糊，有时能靠工具复原，公开的那类还原案例多数也是这种。稳妥做法是用不透明的色块直接盖住，盖严实，别留边
- 车票、登机牌、快递单：盖住二维码、条码、姓名、证件号
- 孩子的照片少发正脸，别带校徽、姓名牌，别写学校和班级
- 截图：裁状态栏、挡聊天列表、去水印

## 4.8 家人

跟爸妈约一个暗号。别用生日、名字这类能猜的，用一件只有你们知道的事。

告诉他们三句话：

- 不转账
- 不点链接、不扫码
- 先挂电话，再打你原来的号码确认

还要告诉他们：现在 AI 能模仿声音，也能换脸打视频，声音和脸像都不能信。

接到 96110 的电话一定要接，那是反诈专线。

有空帮他们把手机里的"手机号搜索""通讯录推荐"也关掉。

家里老人的收件地址，尽量也用驿站。

## 4.9 设备

- **锁屏**：6 位以上，别用生日，别用图案
- **查找设备**：iPhone 的"查找"、安卓的"查找手机"，确保是开着的
- **权限最小化**：通讯录、位置（改成"仅使用期间"）、相册、麦克风，用不上的全关
- **输入法**：关掉云同步、剪贴板同步、云联想。你打过的字，可能被上传
- **公共 Wi-Fi 和公共充电桩**：别用来支付，别接来路不明的 USB
- **旧手机**：退出所有账号 → 关掉查找设备 → 恢复出厂 → 再塞满无关文件，再恢复一次
- **旧号卡**：注销前先解绑，销号后要回执

## 4.10 这几类人要更小心

**未成年人**

- 账号由家长代管，不填真名、学校和班级
- 关掉同城、附近的人、通讯录推荐
- 不发校服、校徽、校车、放学路上的照片

**主播、自媒体**

- 单独的号、单独的设备
- 不露真实姓名，不露小区，不露常去的那家店
- 行程延迟发布，别实时发
- 背景固定，但要有窗帘，别让窗外入镜
- 打赏和转账信息别公开展示

**公职人员、正在打官司的人**

- 单位公示里的联系电话，换成办公电话
- 别用私人号当业务号
- 把所有能证明生活轨迹的内容先收起来

**老板、个体户**

- 企业年报里的联系电话，换成专门的号
- 注册地址能用园区地址或者代账地址，就别用家庭住址

## 今天就能做完的五件事

1. 关掉所有平台的"通过手机号找到我"和"通讯录匹配"
2. 查一遍名下有几个手机号
3. 把不用的老账号注销，旧号解绑
4. 快递地址改成驿站，名字改成化名
5. 跟家里人约一个暗号
