# 第三部分 自查：把自己查一遍

想防住，先自己当一次靶子。

## 3.1 三条规矩

- 只查你自己，或者明确同意让你查的人
- 查到的东西别下载、别保存、别转发
- 查出来的口子，当场就改，别拖到明天

## 3.2 查你名下有几张手机卡

这件事分两个服务，别混成一个：

**一、电话卡的"一证通查"**

工信部推出的，查你名下在三大运营商各办了几张电话卡、一共几张。

**二、互联网账号的"一证通查"**

后来加的一版，能查你名下注册了哪些互联网账号。

要注意：**它查的是一份固定名单里的平台**——阿里、腾讯、字节、美团、京东这些旗下的常见应用，不是全网。

名单会更新，以官方页面为准。所以这套查不到的小网站，不代表你没注册过。

两个服务在同一个入口，支付宝或者微信里搜"一证通查"，进去会让你选查哪一项。[官方]

顺便把运营商 App 里的"副卡管理""亲情号""名下号码"也翻一遍。

查出来有不认识的号，当天去营业厅注销，并且要一份书面说明。

那不是你的号，但出了事第一个被找上的是你。

## 3.3 试一遍平台的找回密码页，看它露多少

做法很简单：打开你常用平台的登录页，点"找回密码"，输入你自己的手机号。

你会看到三种情况：

- 有的平台直接显示：你的手机号是 138\*\*\*\*12 这样，只看得到前 3 位和后 2 位
- 有的显示你绑定的邮箱，邮箱也可能被打码
- 有的直接告诉你："该手机号未注册"

具体显示什么，各平台不一样，以你手机上实际看到的为准。[经验]

**前 3 位加后 2 位，这个片段很危险。**

中间那几位是可以一个一个试的。有人在通讯录匹配这类功能上做比对，就能把号补全。

补全之后，手机号就是所有账号的钥匙。

**"该手机号未注册"这句话本身也是信息。**

对方拿一个手机号，把常见平台挨个试一遍注册或者找回，就能列出一张清单：这个号注册过哪些平台。

这叫账号枚举。手机号是钥匙，这张清单就是钥匙能开哪些门。[经验]

所以你现在要做的：

- 把常用平台挨个点一遍"找回密码"，记下哪些会露出你的号码
- 记下哪些平台能被搜到、能被匹配
- 然后去关掉"通过手机号找到我"（怎么关看 4.2）

一句话提醒：这套动作只能在你自己号上做。

## 3.4 查你的信息在不在泄露数据里

先说一条红线。

**别在任何来路不明的"开盒查询""查自己有没有被泄露"的网站上输入手机号和身份证号。**

十个里有九个是来收料的。你输一次，等于亲手把自己的信息交出去一次。

能用的办法：

- 邮箱：Have I Been Pwned，这是国外的，按邮箱查有没有出现在已知泄露里。只用邮箱，别用手机号
- 看邮箱里有没有平台的"检测到异常登录""请尽快修改密码"通知
- 进常用平台的"安全中心"，看登录设备列表和风险提示
- 检查邮箱有没有被设置自动转发规则——账号被入侵后，这是最常见的后手

说实话的部分：**手机号在国内没有可信的公开泄露查询渠道。**

所以别指望"查一下没事就放心了"。查不到，不代表没泄露。

## 3.5 查你的公开足迹

拿搜索引擎，搜这几样：

- `"你的真名"`，加引号是精确匹配
- 真名 + 城市
- 真名 + 公司名 / 学校名
- 你的手机号，完整的和片段都试
- 你常用的昵称、邮箱、游戏 ID
- `site:github.com 你的邮箱`，限定在某个站里搜
- `filetype:xls 你的真名`，专门找公示类的表格文件

图片也要搜：把你的头像、自拍拿去百度识图、Google 图片，看看被转到哪里去了。

老账号也别放过：贴吧、豆瓣、知乎的历史发言，很多人早忘了自己说过什么。

网盘也能出事：在百度网盘之类的搜索里搜自己的名字加公司，有些人的文件是公开分享的。

查出来之后：

- 能删的删掉
- 删不掉的找平台申诉
- 找客服没用的，看 5.4

## 3.6 查照片里的 EXIF

**先分清你手里是哪一种图**，不然白查：

- 相机拍的原始文件：信息最全，要查就查这种
- 从微信、微博保存下来的：多半已经被压过，字段所剩无几
- 截图：基本不含拍摄信息

所以别拿别人发你的图去查，那说明不了他有没有暴露位置。反过来也一样，**别以为自己发出去的图一定带 GPS**——到底带没带，自己验一遍最准。

**手机上看**：相册里点开一张照片，"详情"或者"信息"里，能看到拍摄时间和地点。

**电脑上看**：Windows 右键照片 → 属性 → 详细信息；macOS 用"预览"打开，然后显示检查器，或者右键"显示简介"。

注意一件事：**别把照片上传到网上的"在线 EXIF 查询"网站。** 那等于把照片直接交给对方。

去掉 EXIF 的办法：

- 导出的时候选"不包含位置信息"
- 用图片工具重新保存一遍，或者压缩一下
- 直接截图，截图一般不带原始 EXIF
- 微信发的时候不勾"原图"

现在就去翻一翻，你以前发过多少张原图。

## 3.7 查老账号

**翻邮箱。** 搜这几个词：欢迎注册、验证、激活、订单、订阅、退订。

搜出来的，就是一份你注册过的网站清单。

**翻短信。** 搜"验证码""登录"，能看到你最近在哪些平台活动。

**翻密码管理器。** 手机自带的钥匙串、浏览器保存的密码，里面存着你早就忘了的站点。

**翻授权。** 微信和 QQ 里都有"授权管理"，能看到你用微信登录过哪些第三方 App。

这份清单通常最惊人——几十个你根本不记得的应用，都拿着你的微信信息。

处理办法一样：还在用的改密码，不用的去注销。

## 3.8 查你的身份证号能不能被算出来

身份证号 18 位，分四段：[标准] GB 11643《公民身份号码》

- 前 6 位：户籍地的行政区划代码，精确到区县
- 中间 8 位：出生年月日
- 后面 3 位：顺序码
- 最后 1 位：校验位

顺序码的意思是：同一个地区、同一天出生的人，按顺序编号。

**而且奇数分给男性，偶数分给女性。**

校验位不是随机的，是按前面 17 位用固定算法算出来的，全国统一。

所以结论要说得准一点。

**别人同时知道了你的户籍地（精确到区县）、出生年月日和性别，范围就会被缩得很小。**

同一个区县、同一天出生的人，顺序码本来就只有一千个，按性别再分一半。校验位不用猜，是算出来的。

但也别把它想成"随手一算就有"：

- 不是每个号都发出去过，真实存在的只是其中一部分
- 要把号试出来，得拿去逐个核验，会留下痕迹
- 现在多数正经业务，除了姓名和身份证号，还要人脸或者短信验证

所以准确的说法是：**这三样同时泄露，你的身份证号就不再是秘密了。**

这值得防，但不必恐慌。

套话的人要问的就是这三件事：你是哪里人？哪年生的？资料上写的是男还是女？

现在自查，这三样你是不是同时公开过：

- 社交账号资料里填了真实生日和性别
- 简历里写了籍贯
- 群昵称、群备注里带着地名加真名
- 学校、单位的公示里有你的户籍地
- 寄快递时寄件人信息写全了

再说一句：光有身份证号，很多业务也办不了，一般还要人脸或者短信验证。

但姓名加身份证号就是"二要素"，能过一部分风控比较弱的核验。

所以别觉得"反正还要人脸，无所谓"。

## 3.9 自查记录表

挨着做完，把结果填在后面：

- 名下手机号 ____ 个，主号是 ____，不认识的号 ____
- 会露出手机号片段的平台：____
- 邮箱 ____，在泄露库里查过没有：____
- 已经开了二次验证的账号：____
- 已经关掉手机号搜索的平台：____
- 生日是否公开：____ 籍贯是否公开：____ 手持身份证照给过谁：____
- 常用收件地址，现在是门牌还是驿站：____
- 和家里人的暗号，约了没有：____

填完的这张表，跟 2.1 那张单子放一起。

别放网盘。

## 小结

自查的目的不是让你害怕，是让你知道从哪下手。
