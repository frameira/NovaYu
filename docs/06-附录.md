# 第六部分 附录

## 6.1 官方渠道

**一证通查（电话卡）**

工信部的服务。查你名下在三大运营商各办了几张电话卡。[官方]

**一证通查（互联网账号）**

同一个入口下的另一项服务。查你名下注册了哪些互联网账号。

**它只覆盖一份固定名单里的平台，不是全网。**名单以官方页面为准。[官方]

搜索"一证通查"，认准工信部反诈专班。

**国家反诈中心 App**

公安部出的，来电预警、诈骗举报、身份核实。

**96110**

反诈专线。打给你的电话一定要接，那是有人在提醒你可能正在被骗。

**12321**

网络不良与垃圾信息举报。管骚扰电话、垃圾短信、不良网站。

**12377**

网信办违法和不良信息举报中心。管网络上的违法信息，包括人肉搜索。

**12389**

公安机关举报投诉电话。报案不受理、不给出具回执的时候可以打。

**12356**

国家卫健委设置的全国统一心理援助热线，2025 年 5 月 1 日起全国统一使用，各地原有心理热线都并入了这个号。被开盒之后失眠、恐慌、不敢出门，可以打这个。

**各平台安全中心**

微信、QQ、支付宝、抖音里都有。处理账号被盗、被冒充、被恶意注册。

## 6.2 一页速查

**今天关掉这几个开关：**

- [ ] 允许通过手机号找到我
- [ ] 允许通过微信号、QQ 号找到我
- [ ] 向我推荐通讯录好友
- [ ] 允许陌生人看我的朋友圈和动态
- [ ] 在附近的人、同城页里展示我
- [ ] 相机的定位
- [ ] 发照片时勾选"原图"

**今天做完这几件事：**

- [ ] 地址改成驿站或者小区门口
- [ ] 收件名字改成化名
- [ ] 查一遍名下有几个手机号
- [ ] 一个账号一个密码，重要的开二次验证
- [ ] 跟家里人约一个暗号

**三个开关的自测办法：**

找个朋友，拿你的手机号搜你，搜不到就算关好了。

## 6.3 应急卡（可以打印）

**被开盒后的头一个小时：**

1. 改密码，先邮箱，再微信和 QQ，再银行
2. 踢掉不认识的登录设备
3. 关掉手机号搜索和通讯录匹配
4. 查邮箱有没有被设置自动转发
5. 打运营商客服，问有没有短信转移和副卡
6. 关掉不认识的免密支付
7. 截图取证：账号名 + ID + 时间 + 内容 + 链接
8. 通知家里人
9. 不对骂

**报案要带：**

身份证、打印好的证据、书面经过、损失证明、时间线。

**一句话跟警察说清：**

我的哪些信息被公开了，造成了什么后果，我怀疑信息是从哪里来的。

**要一份受案回执。**

## 6.4 术语表

**开盒 / 开户**

把匿名账号背后的真人身份挖出来并公开。"开户"是谐音写法，跟银行开户无关。

**社工库**

社会工程学数据库。泄露的数据汇集到一起，建索引供查询。

**脱库**

数据库被整体导出。

**撞库**

拿一个网站泄露的账号密码，去别的网站试。

**二要素**

姓名加身份证号。

**三要素**

姓名、身份证号、手机号。

**前三后2**

平台在找回密码页露出的手机号片段：前 3 位加后 2 位。

**账号枚举**

拿一个手机号挨个平台试注册或找回，反推出这个号注册过哪些平台。

**二次放号**

你买到的手机号以前有人用过。前任机主没解绑的账号，可能被验证码打开。

**号码焕新**

运营商提供的服务。能把前任机主绑过的互联网账号批量解绑。

**内鬼查询**

有查询权限的人违规查别人。

**EXIF**

照片里的隐藏信息。可能包含拍摄时间、设备型号、GPS 坐标等。注意是"可能"——有没有这些字段，取决于拍摄设备、系统设置、文件怎么处理和发到哪个平台（见 2.8）。

**AI 拟声、AI 换脸**

用 AI 模仿你家人的声音或者脸来行骗。暗号就是防这个的。

## 6.5 法律条文

**《刑法》第二百五十三条之一**

侵犯公民个人信息罪。非法获取、出售、提供公民个人信息，情节严重的，处三年以下有期徒刑或者拘役，并处或者单处罚金；情节特别严重的，处三年以上七年以下有期徒刑。

**《刑法》第二百八十五条、第二百八十六条**

非法获取计算机信息系统数据罪、破坏计算机信息系统罪。攻击系统、越权调用接口取数据，走的是这两条。

**《民法典》第一千零三十二条到第一千零三十九条**

隐私权和个人信息保护。明确自然人的私人生活安宁、私密空间、私密信息受保护。

**《个人信息保护法》**

处理个人信息要取得同意，要最小必要。泄露要报告、要补救。

**《反电信网络诈骗法》**

电话卡、银行卡的实名管理，以及反诈的处置措施。

**《治安管理处罚法》**

写恐吓信、发送骚扰信息、散布他人隐私，可以拘留罚款。

**两高《关于办理侵犯公民个人信息刑事案件适用法律若干问题的解释》（法释〔2017〕10 号）**

定"情节严重""情节特别严重"的数量标准。行踪轨迹信息、通信内容、征信信息、财产信息 50 条以上；住宿信息、通信记录、健康生理信息、交易信息 500 条以上；其他公民个人信息 5000 条以上。

具体条文以最新版本为准，打官司请咨询律师。

## 6.6 常见问题

**我不是名人，会有人开我吗？**

会。饭圈、游戏、二手交易、情感纠纷、直播打赏，都可能招来开盒。成本很低，这才是麻烦的地方。

**我改了密码是不是就没事了？**

不是。密码只是其中一环。对方手里如果有你的手机号和身份证号，光改密码不管用。要按第四部分把面收一遍，重点查短信转移和自动转发规则。

**注销账号有用吗？**

有用，但要连绑定一起处理。只注销账号不解绑手机号，等于没做。

**网上那些"开盒查询""查老赖"的网站能用吗？**

不能。它是来收你的信息的。你用一次，等于把自己的资料送出去一份。

**对方说给钱就能删帖，怎么办？**

不要给。这是二次诈骗。留好证据，走 5.4 和 5.5。

**手机号换了就安全了吗？**

换了要记得去各个平台改绑定。旧号不解绑，还是一把钥匙。

**平台举报了没人管怎么办？**

继续举报，同时向 12377 举报平台。保留每一次通知的记录，后面平台要担责。

**我的信息好像是从某个单位流出来的，怎么判断？**

看精准度。如果对方报出的信息只有某个系统里才有——比如内部的业务编号、只有后台能看到的备注——那基本可以确定。报案时把这一点写进笔录。

**未成年人被开盒怎么办？**

家长出面处理。未成年人信息受法律特别保护，报案时说明对方涉及的是未成年人信息，处理会更严。

**怎样才能不被查到？**

做不到百分之百。能做到的是：让查你的人成本变高，让查到的东西过时、对不上、不完整。

## 6.8 来源与延伸阅读

这本书里的说法，大部分来自公开的法律条文、国家标准和官方公告。把出处集中列一下，方便你自己去核。

**怎么读正文里的标注**

正文有些句子后面带方括号，一共六类：

- `[官方]` 政府部门、运营商公开的文件或服务说明
- `[法律]` 法律、司法解释原文。都能在国家法律法规数据库核对
- `[标准]` 国家标准、行业标准
- `[平台]` 平台自己的帮助文档或设置页
- `[案例]` 法院、检察院、公安机关公开的案件
- `[经验]` 没有公开出处，是实践中的观察。会随版本、地区、时间变化

一条原则：**能给出出处的就标出处，给不出的就老实标 `[经验]`，不假装有来源。**

**公开案例**

快递行业卖信息，是国内判得最多的一类。下面两起是公开报道过的：

- 广东深圳宝安，两名快件处理员利用分拣集包的便利，出售快递面单信息 **2.1 万余条**，法院以侵犯公民个人信息罪分别判处有期徒刑，并处罚金。
  [案例] 中国法院网：<https://www.chinacourt.cn/article/detail/2026/08/id/9437103.shtml>
- 江苏常州钟楼，快递公司员工庄某、朱某出售客户信息，经检察院提起公诉，法院判处**有期徒刑十个月**，各并处罚金。
  [案例] 京报网：<https://news.bjd.com.cn/2026/04/26/11711949.shtml>

这两起说明两件事：

- **一条快递信息在市场上只值几毛钱，卖到上万条就是刑事案子**
- 判决结果不只是刑期，还有罚金；作案用的手机这类工具会被没收

想要更多案例和案号，去**中国裁判文书网**，按"侵犯公民个人信息罪"加"快递""通讯""房产"这些关键词检索。新闻报道一般不写案号，判决书里才有。
